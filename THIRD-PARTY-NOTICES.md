# Third-party notices

FetchForge initially invokes external command-line tools installed by the user rather than bundling their executables.

- **yt-dlp** — a separate project. Review its current license and the license notices for the exact executable/build you install: https://github.com/yt-dlp/yt-dlp
- **FFmpeg** — a separate project. Its license depends on the build configuration and enabled components: https://ffmpeg.org/legal.html

The MIT license in this repository applies to FetchForge's original code, not to third-party dependencies. If the project later distributes binaries for these tools, review the precise build configuration, license texts, attribution, and corresponding-source obligations before publishing a release.
